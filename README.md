## Overview

Anonine VPN provides a Windows desktop interface for sending traffic through encrypted VPN connections while allowing users to decide how the service operates. The client combines convenient access to a global server network with responsive connection controls and privacy-oriented tools for Windows 10 and Windows 11.

Its workflow is intended to stay simple: connect with one click, use AES-256 encryption, and enable the protections that match your needs. Split tunneling, DNS leak protection, and a kill switch give users additional control without requiring a complicated desktop interface.

---

## Key Capabilities

- AES-256 encryption for handling traffic through a protected connection
- No-logs policy support designed to limit connection data retention
- Kill switch protection that can stop traffic after an unexpected VPN interruption
- Global server network with multiple location choices
- One-click connection for fast startup and reconnecting
- Split tunneling for excluding selected applications or traffic from the VPN tunnel
- DNS leak protection to help route DNS requests consistently through the VPN session
- Compatibility with Windows 10 and Windows 11

## Using the Client

1. Start Anonine VPN on Windows.
2. Pick a location from the server list, or select quick connect.
3. Enable the VPN session.
4. Configure split tunneling when particular applications or traffic should remain outside the tunnel.
5. Keep DNS leak protection active when consistent VPN-based DNS routing is important.
6. Enable the kill switch if disconnected traffic should be blocked automatically.

A normal session can be handled as follows:

- Launch the client
- Choose a server
- Establish the connection
- Confirm that the session is active
- Fine-tune split tunneling and other protection settings when necessary
